Upgrade

Boot the new release's ISO on the installed machine and run:

flxupgrade
doas xpkg upgrade

What it replaces: the system files (/usr /bin /sbin /lib, /init), the /etc files the new release has and yours lacks, and the kernel plus Limine on the boot partition.

What it keeps: your /etc settings, users, installed packages and all of /home. Then xpkg upgrade moves the packages to the new repo state.

Never replace the files of a published release by hand — bump the version instead. The version stamps /etc/os-release, the banner and the boot menu together, and /init compares it against the one on disk to decide what needs refreshing.
