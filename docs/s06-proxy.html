Step 6: setup-proxy

Default is no proxy (the prompt reads [y/N] and means it). Saying no writes an empty /etc/proxy.conf and removes the profile hook — a stale proxy from a previous install is a failure nobody can explain later. Answering yes and then giving an empty host counts as no, not an error.

With host, port (default 8080), optional user and password:

/etc/proxy.conf           the URL, 0600 (auth line appended if any)
/etc/profile.d/proxy.sh   HTTP_PROXY HTTPS_PROXY http_proxy https_proxy, exported

A scheme-less host is completed as http://, which is what people type. Three things read it: the installer now, xpkg as environment, and anything you start later via /etc/environment.
