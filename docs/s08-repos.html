Step 8: setup-apkrepos

Despite the name, FreeLinX uses xpkg, not apk. The file is /etc/xpkg/repos.conf, one URL per line, highest priority first. The default is a public dataset over HTTPS — reading needs no account or token, only publishing does, and installing does not publish.

https://huggingface.co/datasets/FreeLinX/packages/resolve/main

The step writes the file directly instead of appending, so re-running replaces the entry instead of doubling it. Then it runs xpkg update. A failed refresh is not fatal — the install can finish and the network can be fixed after — but it says so instead of pretending. An http:// URL warns (xpkg will not step HTTPS down to HTTP) and asks again.
