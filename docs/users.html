Users

doas flxadduser bob            # plain account
doas flxadduser bob --admin    # wheel too, so doas works

Only wheel may use doas. The rule in /etc/doas.conf:

permit persist :wheel

The file is 0600. The image's doas.conf already carries rules for power and network tools; new installs append the wheel rule instead of rewriting the file and dropping them.

Passwords

Everything goes through flxpasswd and libc crypt(3), stdin only. /etc/shadow is 0600, /root 0700, /tmp 1777. The escalation binaries are setuid, nothing else is:

doas unix_chkpwd su newgrp   # 4755, and that is all

The live user is gone

Install removes live from passwd, shadow and group, deletes the passwordless doas rule and /home/live. Whatever was convenient on the medium does not follow you onto the disk.
