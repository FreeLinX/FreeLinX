Step 4: setup-passwd

Sets the root password. Typed blind — echo is off while you type, and only echo is restored after, because restoring a saved stty state fails on this stty and used to leave the terminal silent.

  • Empty is refused. An empty root account is a remote shell for anyone who reaches the machine, and pressing return too many times must not create one.
  • Under 6 characters warns and asks. Type it twice; a mismatch starts over.

The hash is made by flxpasswd, which calls libc's crypt(3) — the same code that verifies it at login. The password travels on stdin, never in argv where ps could read it. After setting, the step reads /etc/shadow back and refuses to continue if the field is empty, locked (!) or unusable (*). Trust, then verify.
