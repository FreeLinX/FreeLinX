Hardware

Boot

  • BIOS and UEFI both work. One ISO, Limine for both.
  • Secure Boot must be off. The image carries Limine directly; there is no signed shim, so a board enforcing signatures refuses it.
  • Serial console works. The kernel line keeps console=ttyS0,115200 for headless machines, with console=tty0 last so the screen stays the primary console.

Disks

The installer looks for real disks only:

/dev/sd?  /dev/nvme?n?  /dev/vd?  /dev/xvd?  /dev/mmcblk?

Partitions are never offered — partitioning /dev/sda1 is not a thing anyone means. CD-ROM devices are skipped. A disk with anything mounted is refused outright.

Minimum disk: 8 GB. Below that the installer stops and changes nothing.

Firmware

Real wifi, GPUs and audio codecs need vendor blobs. They come from the linux-firmware package in the image. A build with an empty /lib/firmware is refused rather than shipped: a module loads, finds no blob, and sits there with the radio off, silently. If your wifi card is dark after install, missing firmware is suspect number one.

/lib/modules holds exactly one kernel version — the one the image boots. Two versions in there once meant modprobe could load nothing.

Keyboard

One honest limitation: Linux removed the ioctl that used to re-layout a running text console, so the installer records your layout (/etc/conf.d/loadkmap.conf, /etc/flx-kbd) but cannot apply it to the live console. The console keeps the layout it booted with.
