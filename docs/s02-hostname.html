Step 2: setup-hostname

Default is the current name, or freelinx. The name must be RFC 1123: letters, digits, dots and dashes, in labels of 1–63 chars, 253 in all, no label starting or ending with a dash. Anything else is refused with the reason, not a shrug.

It goes in three places, because all three are needed:

hostname "$name"        # this boot, now
/etc/hostname           # survives reboot
/etc/hosts              # so local resolution never stalls on DNS

/etc/hosts is rewritten whole:

127.0.0.1	localhost localhost.localdomain
::1		localhost localhost.localdomain
127.0.1.1	your-name

127.0.0.1 stays on the first line. Some software assumes the loopback resolves through it.
