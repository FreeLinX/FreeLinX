Install

xsetup                  # every step not done yet, in order
xsetup --list           # the steps
xsetup --status         # which are done
xsetup --reset NAME     # forget one step, so it runs again
xsetup setup-sshd       # run one step on its own

Progress lives in /etc/xsetup.state because it must survive a reboot mid-install. A step that fails is not recorded, so a typo never becomes permanent. Only setup-disk writes to a disk.

The thirteen steps

#StepDoes
1setup-keymaprecords the keyboard layout
2setup-hostnamenames the machine, three places
3setup-interfaceswired dhcp/static/off, plus wifi
4setup-passwdroot password, empty refused
5setup-timezoneRegion/City menus, copies the zone
6setup-proxyHTTP proxy or none, default none
7setup-ntpntpd on, or nothing
8setup-apkrepospoints xpkg at the signed repo
9setup-usera normal account, wheel optional
10setup-sshdssh daemon, off unless you insist
11setup-diskthe disk. erases it. asks first.
12setup-lbuwhere changes are kept
13setup-apkcachewhere downloads are kept

Each step also runs standalone and asks nothing twice. The menus print no color at all — white text survives pipes, logs and serial lines, which is how the installer is tested and how headless machines read it.
