Step 9: setup-user

A system used only as root is a system where one typo is fatal. This step makes somewhere else to stand.

Names take letters, digits, dash and underscore, must start with a letter or underscore, 32 chars at most. Upper case is folded to lower, out loud (Kanan -> kanan), because passwd lookups are case sensitive and a mixed-case name is a trap for whoever comes next.

Accounts start at uid/gid 1000, first free wins. The shell comes from /etc/flx-shell (mksh on base). Home is made now under /home, mode 700, and moved onto FLX_HOME by setup-disk later.

Membership: a group of its own plus audio video input storage users — and wheel only if you say yes when asked. It is asked, not assumed: an account meant to be ordinary used to land in wheel anyway and could become root with its own password.

Password is optional here, unlike root's. Empty warns that anyone reaching the machine can log in as them, and prints the one-liner that sets one later from a root shell.
