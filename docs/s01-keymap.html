Step 1: setup-keymap

A numbered menu of 24 layouts: us gb ca ie de at ch es it pt nl be se no dk fi pl cz hu ro tr ru gr — plus "no change". Pick one.

It is recorded in two places:

/etc/conf.d/loadkmap.conf   KEYMAP=us
/etc/flx-kbd                 us

The second is the layout a desktop installed later starts X with.

What it does not do: change the running console. Linux removed the ioctl that allowed it, so there is no interface a program can use. The step says so plainly instead of pretending. The console keeps the layout it booted with; the choice waits for a later system that can use it.
