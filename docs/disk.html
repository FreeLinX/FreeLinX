Sizes: on disks of 20 GB and up the system takes 30% (clamped 6–64 GB); on smaller disks 40% (at least 3 GB). /home runs to the end of the disk. Same rule as the desktop installer — one rule, two installers.

Two kinds of identity

The kernel finds / by GPT partition GUID (root=PARTUUID=), read straight out of the table at LBA 1: entry array position, entry size, GUID 16 bytes in, first three fields little-endian. The filesystem UUID would need an initramfs to resolve, and there is none — so the kernel gets the partition's own GUID instead.

/init and /etc/fstab then use filesystem UUIDs from blkid, pinned in /etc/flx-disk:

FLX_ROOT_UUID=...
FLX_HOME_UUID=...
UUID=...  /      ext4  defaults,noatime  0 1
UUID=...  /home  ext4  defaults,noatime  0 2
tmpfs     /tmp   tmpfs mode=1777,nosuid,nodev  0 0

Labels alone are never trusted: another disk carrying FLX_ROOT must never be mounted by accident. A system with no pin still finds FLX_HOME by label as a fallback.

Around the writes

  • Partition nodes are waited on (mdevd makes them): 20 tries, half a second apart, then give up loudly.
  • /run/flxinstall-active tells the automounter to step aside before partitioning; cleanup removes the flag and unmounts /mnt/flx_root /mnt/flx_boot /mnt/flx_home on every exit path, including interrupts.
  • limine bios-install is pointed at the disk and the BIOS boot partition number. If it fails, it warns and the disk boots UEFI only.
