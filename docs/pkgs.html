Packages

xpkg install <name>
xpkg list
doas xpkg upgrade
xpkg clean                 # empties /var/cache/xpkg

~428 packages in the signed repository. The index signature is Ed25519, checked against /etc/xpkg/keys/freelinx.pub; every archive is checked by sha256 on top. xpkg refuses a repo whose index it cannot verify, so an image without the key installs nothing.

The address lives in /etc/xpkg/repos.conf, one URL per line, highest priority first. The image carries a package database describing what is installed, so xpkg upgrade and everything installed later see the base as installed instead of stacking a second copy on top.

Where packages come from

The ports tree builds the console set (mandoc, less, iproute2, lsof, mksh, stty, tcc and friends). The desktop stack produces the rest and publishes the archives; the base build takes the ones it keeps by name from the same signed repo your machine updates from. One repo, both directions.
