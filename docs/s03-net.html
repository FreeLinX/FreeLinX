Step 3: setup-interfaces

Interfaces are found by looking at what the kernel made — /sys/class/net/* with a device behind it. No guessing names. lo and virtual interfaces are not questions.

Wired

Each wired interface: dhcp, static, or off. Static takes an address (192.168.1.10/24, the /24 is added if you omit it), an optional gateway and nameserver. Only the step's own block of /etc/dhcpcd.conf is rewritten; the rest of the file stays.

Wireless

The first wireless interface is offered for setup. SSID plus passphrase go to /etc/wpa_supplicant/flxwifi.conf, mode 0600, because the file holds a password in the clear:

  • The SSID is stored as hex — SSIDs are arbitrary bytes, quotes and UTF-8 included.
  • The passphrase never appears on a command line. The 64-hex-digit PSK is derived with wpa_passphrase reading from stdin, and WPA3's sae_password is written only when the text is quotable.
  • 8–63 characters, no newline. An open network stores key_mgmt=NONE.

After writing, the flxwifi service is restarted so it connects now, not just at boot.
