Network

Wired

dhcpcd, started by /init. Static addresses and per-interface policy live in /etc/dhcpcd.conf in the block xsetup wrote; only that block is rewritten on re-runs. denyinterfaces leaves an interface alone.

Wifi

/etc/wpa_supplicant/flxwifi.conf   # 0600, passwords in the clear

Written by step 3, read by the flxwifi service at boot. SSID as hex, PSK as 64 hex digits, WPA-PSK + WPA-PSK-SHA256 + SAE where quotable. Restart the service to reconnect now instead of at boot.

sshd

/etc/ssh/sshd_config:
PermitRootLogin prohibit-password
PasswordAuthentication yes
KbdInteractiveAuthentication no
Subsystem sftp /libexec/sftp-server

Root over ssh needs a key, never a password. Privilege separation user sshd, locked, shell nologin, home /var/empty. Logs to /var/log/sshd.log. Off until step 10 says otherwise.

Time

ntpd, enabled by default. A wrong clock fails certificate checks, so the first sync matters more than the daemon's manners.
