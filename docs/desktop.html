Desktop

One line when you want it, not before:

xpkg install xorg xinit openbox      # pulls in fonts, st and the keymaps
startx

Right-click for the menu: terminal, reconfigure, restart, exit. With no ~/.xinitrc, startx brings up openbox with an st terminal.

Your own ~/.xinitrc should end in:

exec openbox --startup st

A terminal started next to openbox can come up before openbox manages the screen and never show. Ending in exec avoids that race.

xpkg install xrandr
xrandr -s 1920x1080
xpkg install firefox

The console screen size (xres/yres) is the size X takes too. Firefox is the biggest thing in the repo — install it on an installed system, not in a small live session.
