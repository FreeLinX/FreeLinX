Step 10: setup-sshd

Two choices: none, or openssh. None removes the link if a previous run put it there.

Enabling warns first, in plain words: anyone who can reach the machine and knows an account may log in over the network, so the root password from step 4 should not be the only thing between them and a shell. Then it asks confirmation anyway.

Host keys are generated once per machine, at setup time:

ssh-keygen -q -t ed25519 -f /etc/ssh/ssh_host_ed25519_key -N ''
ssh-keygen -q -t rsa -b 3072 -f /etc/ssh/ssh_host_rsa_key -N ''

A key baked into an image would be the same key on every machine ever installed from it. /etc/ssh is 700, private keys 600. The service is the usual symlink, /etc/svc/openssh to /var/service/sshd, running sshd -D -e with host keys made on first start if missing.
