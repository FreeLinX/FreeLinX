Step 13: setup-apkcache

Where downloaded package files are kept. xpkg keeps them in /var/cache/xpkg:

  • installed system — /var is on the root partition, so the cache is on the disk and survives reboots.
  • running from RAM — the cache is in RAM and goes with the next reboot.

xpkg clean empties it any time. That is the whole step.
