Step 12: setup-lbu

Where are changes to the system kept. It reads the answer step 11 left in /etc/xsetup-disk-mode and reports, nothing to choose:

  • sys — the system is on a disk. /usr /etc /var /root /bin /sbin /lib are on the root partition, so every change is kept.
  • anything else — the system runs from RAM. Changes are lost on reboot. There is no overlay that saves RAM changes to another disk, and the step says so instead of asking for a disk it would not use. To keep things: xsetup --reset setup-disk, then xsetup.
