No-GNU gate

scripts/check-nognu.sh ROOTFS. Exit status is the number of offending files, so a build script can refuse a tree that is not clean. Current result: 0 failing.

Every ELF over 100 bytes is checked for:

TagMeans
gcc.comment names a GCC compiler
interpinterpreter is not /lib/ld-musl-x86_64.so.1
neededDT_NEEDED on libc.so.6, libgcc_s, libstdc++…
glibcGLIBC_x.y symbol versions
filea GCC runtime library present at all
gnulibDT_NEEDED on ncurses, readline, gettext, gmp…
gnucodeGNU code linked statically, by fingerprint (NCURSES_NO_PADDING, "GNU Readline", gnu.org addresses…) — clang-built GNU code has no GCC mark, so strings are checked too

Known offenders being rebuilt can be listed in check-nognu.allow; they report as waived, not failing. None of the fingerprints occur in the non-GNU software shipped, checked against every image and package.
