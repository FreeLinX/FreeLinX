What is on it

System

  • runit — init and supervision
  • mdevd — device nodes in /dev
  • dhcpcd — wired addressing, static config from its conf
  • wpa_supplicant + flxwifi — wireless, connects at boot
  • ntpd — clock, on by default
  • dbus — the bus everything expects
  • doas — become root, wheel only
  • OpenSSH 10.5 — ssh and sshd, daemon off until you enable it
  • curl, git — fetch things
  • tmux, htop, nnn — live in the terminal
  • vim, and vi as a link to it
  • bc — the calculator is not a joke, it is how you check partition math
  • e2fsprogs, dosfstools — mkfs.ext4 and mkfs.fat, the installer needs both

Console

  • mandoc — man, with ~200 NetBSD manual pages and an index
  • less — the pager, BSD side of its dual licence
  • ip — iproute2
  • lsof — what holds what
  • mksh — the login shell: arrows, history, Tab. /bin/sh stays NetBSD sh, for scripts.

Compiler

cc is tcc, with musl headers, kernel UAPI headers and the start files, so cc hello.c works out of the box. No C++ compiler ships, so no C++ headers ship either.

Kept packages

The image is built from these, installed by name from the signed repo:

ca-certificates dbus expat flxnet libcxx libedit libelf libffi libmd libnl
libudev-zero libxml2 linux linux-firmware musl netbsd-curses nnn openssl pcre2
sqlite toybox tzdata wpa_supplicant xpkg zlib

Plus the console ports: mandoc less iproute2 lsof mksh stty and tcc, plus musl-dev for the headers.

Not on it

No X11, no GTK, no Mesa, no fonts. The repo holds ~428 signed packages for all of that. See packages.
