Step 5: setup-timezone

Region first, then city — the 600-zone flat list would be unusable. Regions with too many cities ask for the full name typed out. Single zones stored as themselves (UCT, Turkey, Singapore and a dozen others) are accepted directly, no phantom city menu.

The zone is a file under /usr/share/zoneinfo (tzdata port), and it is installed as a copy, not a symlink:

cp /usr/share/zoneinfo/Asia/Baku /etc/localtime
Asia/Baku > /etc/timezone
Asia/Baku > /etc/TZ

A symlink breaks when the zone database upgrades or the disk is mounted elsewhere. /etc/TZ is what FreeLinX reads — profile exports TZ from it. Mode 644, saying plainly that it is a copy.
