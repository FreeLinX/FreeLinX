FAQ

Secure Boot says no.
Turn it off. No shim is shipped.

Wifi worked on the installer but not after?
It did not — the live session had the same firmware. Check ip a for the interface, then /etc/wpa_supplicant/flxwifi.conf, then suspect the blob.

Keymap step did nothing.
Correct. It records, it does not apply. Read step 1.

Forgot every password.
Boot the rescue shell from the Limine menu and set new ones with flxpasswd. Physical access is root access; that is true everywhere.

ssh as root asks for a key.
PermitRootLogin prohibit-password. Log in as your user and doas. That is the point.

xpkg fails on certificates.
The clock is wrong. ntpd fixes it in a minute or two; check date.

Nothing is kept after reboot.
You run from RAM. Install with xsetup --reset setup-disk, then xsetup.

Can I reinstall without losing /home?
That is why it is its own partition. Reinstall writes FLX_ROOT; FLX_HOME is reformatted only if you let it partition again — back it up first anyway.

Empty root password?
Refused by the installer, and good. Set one with flxpasswd from a root shell if you ever clear it.

Firefox in the live session?
Needs RAM — the overlay is 75% of it. On small machines, install first.
