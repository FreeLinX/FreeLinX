Philosophy

FreeLinX base is a console system. No desktop ships in the image. You get a login prompt, a manual, a C compiler, and a package manager. The rest is your decision.

Rules it follows

  • Small. The live session starts in about 60 MB of RAM. The ISO is ~290 MB. What is not needed is not shipped.
  • Plain. Configs are text files. Services are directories with a run script. Enabling one is a symlink.
  • No GNU. The userland is NetBSD, the C library is musl, the compiler chain is LLVM plus tcc. A script refuses the build if GNU code slips in.
  • Honest installer. It says what it will do before it does it. The only step that writes to a disk asks for the word yes first. The default is to write nothing.
  • Resumable. Every install step is recorded. Pull the plug mid-install and it carries on where it stopped.

What it is not

  • Not a desktop distro. X arrives with one xpkg line, when you ask for it, not before.
  • Not systemd. Init is runit. Service supervision is runsvdir, nothing more.
  • Not sudo. Privilege escalation is doas, for users in wheel.
  • Not forever-running-from-RAM. The installed system runs from its disk like any other system. RAM mode exists for trying, not for living.
