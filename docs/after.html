After install

Reboot, remove the stick, boot the disk. Every console asks for a login now — the live shell is gone with the live user.

passwd                      # change your password (users go through doas)
doas flxadduser bob         # another user; --admin also allows doas
doas xpkg install tmux      # packages; doas xpkg upgrade updates them

First hour checklist

  • man man — confirm the manuals work.
  • ip a — confirm the interface from step 3 came up.
  • xpkg update && doas xpkg upgrade — confirm the repo from step 8 answers.
  • date — confirm ntpd is dragging the clock right.
  • cc --version — tcc answers; try cc hello.c.

Files you wrote in /home survive reboots — that is the point of FLX_HOME being its own partition. Everything under / survives too; only /tmp is RAM.
