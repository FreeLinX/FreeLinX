USB boot

lsblk
sudo dd if=freelinx-base-x86_64.iso of=/dev/sdX bs=4M conv=fsync

Check with lsblk that /dev/sdX is the stick. dd erases it. There is no undo.

Boot the stick. The menu offers the system and a rescue shell. Pick the system. You land in a root shell on tty1–tty3 and on serial. Nothing is kept until it is installed — that sentence is also the first thing on the screen, in /etc/motd.

From here: xsetup. Thirteen steps, one question at a time. See install.

If it does not boot

  • Black screen on old BIOS hardware: the image hands over a text screen (textmode: yes) so vgacon has a console with or without a KMS driver. If even that fails, try the serial console.
  • "No bootable device" after install: the disk has no system on it yet. Install first, then boot the disk without the stick.
  • Secure Boot violation: turn Secure Boot off in the firmware setup.
